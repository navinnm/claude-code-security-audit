# 19-control reference checklist

1. Row-level security and tenant isolation.
2. Authentication and authorization on every API route.
3. Server-side enforcement of permissions and business rules.
4. Rate limiting and abuse prevention.
5. Input validation, output encoding, safe deserialization.
6. Parameterized database queries.
7. CORS allowlist and credential policy.
8. HTTPS, secure cookies, trusted proxy configuration.
9. IDOR/BOLA and object-level authorization.
10. Production debug mode and safe errors.
11. CAPTCHA or proportionate anti-automation controls.
12. Admin and security audit logging.
13. Private storage and authorized file access.
14. Admin UI and privileged-operation protection.
15. Dependency vulnerability management.
16. File upload security.
17. Independent AI-assisted review.
18. Security headers.
19. Webhook authenticity, replay protection, idempotency.

Statuses: PASS, FAIL, PARTIAL, NOT APPLICABLE, NOT VERIFIED.
Never infer PASS from absence of scanner matches.
